# 锁屏图片裁剪

单文件静态网页，直接双击 `index.html` 即可使用：无需安装、无需联网，图片不会上传，全部在浏览器本地处理。

## 使用

1. 拖入图片，或点击取景框选择文件
2. 拖动画面定位；拖动取景框的边框或四角等比缩放
3. 需要时旋转图片、调整倍率，右侧实时预览 240 × 240
4. 确认后点击「下载」

输出文件名为 `原文件名_240x240.png` / `原文件名_240x240.jpg`。

## 交互

| 操作 | 作用 |
| --- | --- |
| 拖动画面 | 移动取景范围 |
| 拖动取景框边框 / 四角 | 以中心为基准等比缩放取景范围 |
| 滚轮 / 缩放滑杆 | 连续调整倍率 |
| 倍率输入 | 直接输入任意倍率（如 `4.00`、`4.17`） |
| ↺ / ↻ 90° | 每次旋转 90° |
| 角度滑杆 | 在 ±45° 内微调，可与 90° 旋转叠加 |
| 双击画面 / 复位 | 回到适应视图并居中 |
| 1:1 裁剪 | 每个输出像素对应一个源像素，不重采样 |

## 处理规则

- 取景框比例固定为 240 × 240，框内区域输出为 240 × 240。
- 记 `k` 为一个输出像素对应的源像素数（即倍率输入的值）：
  - `k = 1`：1:1 裁剪，不做缩放和重采样；
  - `k > 1`：缩小取样（高质量插值）；
  - `k < 1`：源图小于目标尺寸，只能放大。
- 倍率由原图尺寸和取景范围共同决定：`倍率 = 取景宽度 ÷ 240`，可以是任意小数，不需要取整；缩放使用浏览器的高质量重采样。
- 旋转围绕取景中心进行；旋转后图片可覆盖的范围会收紧，倍率上限随之自动调整。
- **PNG**：只做无损压缩，不透明像素逐位一致；1:1 且旋转为 90° 的整数倍时像素完全不变。
- **JPG**：会重新编码一次，质量可调（默认 95），透明区域铺白底。
- 手机照片的 EXIF 方向会自动校正。

## 扩展尺寸

编辑 `index.html` 中的 `SIZE_PRESETS`，追加一项即可（支持非正方形）：

```js
const SIZE_PRESETS = [
  { id: '240', width: 240, height: 240, label: '240 × 240' },
  { id: '480', width: 480, height: 480, label: '480 × 480' },
];
```

## 测试

测试页面需要本地静态服务：

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/tests/test.html
```

覆盖：1:1 像素一致性、缩放与边界、倍率输入、拖拽平移、边框缩放、90°/微旋、透明通道、JPG 白底与质量、文件名、UI 状态等。
