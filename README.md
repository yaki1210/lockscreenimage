# 锁屏图片裁剪

单文件静态网页，直接双击 `index.html` 即可使用：无需安装、无需联网，图片不会上传，全部在浏览器本地处理。

## 使用

1. 拖入图片，或点击取景框选择文件
2. 在画面上拖动定位，滚轮或滑杆缩放
3. 右侧实时预览 240 × 240，满意后点「下载」

输出文件名为 `原文件名_240x240.png` / `原文件名_240x240.jpg`。

## 交互

| 操作 | 作用 |
| --- | --- |
| 拖动图片 | 移动取景范围 |
| 滚轮 / 滑杆 | 缩放取景，从「适应整图」到「1:1」 |
| 双击画面 / 复位 | 回到适应视图并居中 |
| 1:1 裁剪 | 每个输出像素对应一个源像素，不重采样 |

## 处理规则

- 取景框比例固定为 240 × 240，框内区域输出为 240 × 240。
- 记 `k` 为一个输出像素对应的源像素数：
  - `k = 1`：1:1 裁剪，不做缩放和重采样；
  - `k > 1`：缩小取样（高质量插值）；
  - `k < 1`：源图小于目标尺寸，只能放大。
- **PNG**：只做无损压缩，不透明像素逐位一致；半透明像素受浏览器预乘 alpha 影响可能有取整误差（alpha 越低越明显）。
- **JPG**：会重新编码一次，质量可在页面调整（默认 95），透明区域铺白底。
- 手机照片的 EXIF 方向会自动校正。

## 扩展尺寸

编辑 `index.html` 中的 `SIZE_PRESETS`，追加一项即可（支持非正方形，预览框会随比例变化）：

```js
const SIZE_PRESETS = [
  { id: '240', width: 240, height: 240, label: '240 × 240' },
  { id: '480', width: 480, height: 480, label: '480 × 480' },
];
```

## 测试

测试页面需要本地静态服务：

```bash
python -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/tests/test.html
```

覆盖：默认覆盖视图、1:1 像素精确、边界限制、拖拽、滑杆、按钮、透明通道、JPG 白底与质量、文件名、UI 状态等。
